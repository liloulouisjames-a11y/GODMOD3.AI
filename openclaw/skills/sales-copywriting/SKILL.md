# Sales Copywriting

Clarity converts. Cleverness decorates.

## Core formulas (pick one, don't blend)

- **PAS** — Problem, Agitate, Solve. Best for landing hero + ads.
- **AIDA** — Attention, Interest, Desire, Action. Best for launch posts & video scripts.
- **JTBD one-liner** — "We help `[who]` get `[outcome]` without `[pain]`." Best for hero lines,
  bios, deck title slides.

## Landing page skeleton

1. **Hero:** JTBD one-liner + subline naming the #1 objection + primary CTA (verb + outcome:
   "Start closing faster", not "Submit").
2. **Social proof strip** — real logos/numbers only; omit the strip rather than fake it.
3. **3 pain→outcome blocks** — headline = outcome, body = 2 lines max, visual per block.
4. **How it works** — 3 steps, zero jargon.
5. **Objection zone** — FAQ targeting the top 4 real objections (mine `objection-handling` logs).
6. **Final CTA** + risk reversal (trial, guarantee — only ones the user actually offers).

## Voice rules

- Grade-7 readability; sentences ≤ 15 words on average; active voice.
- Specific beats superlative: "cuts review time 40%" > "blazingly fast". Numbers need sources.
- One idea per sentence, one CTA per screen, one audience per page.
- Write 3 headline variants per asset (safe / bold / weird) and say which you'd ship and why.

## Workflow

1. Intake: product, audience (ideally an ICP from `lead-generation`), surface, goal metric,
   voice samples if any.
2. Draft in markdown with `[IMAGE: …]` placeholders; iterate with the user.
3. For A/B-able surfaces, deliver the test plan too: variable, variants, success metric,
   minimum run time.

## Rules

- Claims must be true and substantiated by the user; unverifiable ones become bracketed
  placeholders, not published prose.
- Match required disclosures for the channel (e.g., "#ad" for sponsored posts).
